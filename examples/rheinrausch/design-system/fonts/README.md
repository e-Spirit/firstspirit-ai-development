# Fonts

Self-hosted so the page renders without internet. Declared in `css/fonts.css`, used through `css/tokens.css`.

| File | Family | Used for | Licence |
|---|---|---|---|
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque (variable, weights 600 to 800) | headings | SIL Open Font License 1.1, `OFL-Bricolage-Grotesque.txt` |
| `dm-sans-latin.woff2` | DM Sans (variable, weights 400 to 700) | body text | SIL Open Font License 1.1, `OFL-DM-Sans.txt` |
| `Yellowtail-Regular.ttf` | Yellowtail | the script accent in the hero and the logo wordmark | Apache License 2.0, `LICENSE-Yellowtail.txt` |

The two woff2 files are Latin subsets (they cover German: ä ö ü ß €). Yellowtail is the unmodified font file. Other scripts are not
included; take the matching files from [Google Fonts](https://fonts.google.com) if you need them.
